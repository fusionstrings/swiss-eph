## [0.1.0] - 2026-01-14

### Added

- Initial release of `@fusionstrings/swisseph-wasi`
- Complete binding for 95+ Swiss Ephemeris functions
- Native WASM compilation using WASI SDK
- Cross-platform support (Deno, Node.js, Browser, Cloudflare Workers)
- High-precision astronomical calculations matching native C library
- Built-in Moshier ephemeris support
- Optional external Swiss Ephemeris file loading
- Comprehensive test suite comparing against `swetest`
